# Entity Fields


* [[EntityPrototype]]::`PlanetsLib_pipette_result`(string) — Defines the entity summoned when using the pipette tool on this entity. Is mutually exclusive with [[EntityPrototype::placeable_by]]. This only affect pipette behavior, and does not make this entity placeable by the entity's pipette result. A wrapper for `PlanetsLib.constants.pipette_result`.
